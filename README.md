# Customer Segmentation

## Project Overview

This project focuses on grouping customers based on their purchasing behaviour using Python. The aim was to understand how customers differ from one another and identify patterns that could help a business make better decisions.

## Objectives

- Explore the dataset and understand the information it contains.
- Clean and prepare the data for analysis.
- Use clustering to group customers with similar characteristics.
- Examine the different customer groups and understand what makes each group unique.
- Suggest ways a business could use the results to improve its marketing and customer engagement.

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## What I Did

I started by exploring the dataset and checking the data types and quality before preparing it for analysis. I then used clustering to group customers with similar characteristics.

After creating the clusters, I examined the groups to understand their differences and assigned descriptions to make the results easier to interpret. I also used visualisations and a cluster summary to help explain the findings.

## Key Takeaways

The project helped me understand how clustering can be used to identify customer groups with different characteristics. These groups can help a business think about how to tailor its marketing and customer engagement strategies instead of treating every customer in exactly the same way.

## Project File

- customer_segmentation.ipynb — contains the data exploration, preparation, clustering analysis, visualisations, and findings.
